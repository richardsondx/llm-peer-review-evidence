Can newer models detect scientific errors?

GPT-6-Luna and GPT-6.1-Sol review 27 manuscripts directly, using identical text-only inputs. Their newly generated critiques are compared with published SPOT error annotations.

By Richardson Dackam · Independent researcher, Nshipyard

The question behind this project

I wanted to test whether concerns raised in an earlier review of AI peer review—especially missed scientific errors—still apply to newer models. Re-reading old papers cannot answer that performance question. This evaluation asks the newer models to act as reviewers themselves.

The original review and its newer-model source audits cover 27 published studies. The new experiment uses a different set of 27 manuscripts from SPOT. These are two separate research components, not the same 27 experiments rerun.

New reviewer results

Both models use Extra High reasoning. Luna runs first, then Sol. Each manuscript receives one independent review per model, without supplied error annotations or browsing.

“Matched” means an automated judge found the same specific error mechanism at a compatible location. It does not establish that the reference annotation or reviewer claim is scientifically correct.

What the pilot can tell us

Luna matched 8 of 12 specific reference annotations; Sol matched 10 of 12. Both left some specific reference annotations unmatched under this text-only setup. These automated coverage results address one part of the original question: detection of scientific errors. An older-model control was not run on these same inputs, so this pilot does not establish improvement over GPT-4 or reproduce the older studies’ other findings.

The primary measure is coverage of 12 sufficiently specific reference annotations. All 27 papers and 29 selected-category annotations remain visible; vague references and a spelling-only issue are excluded from the primary denominator. The full screening record is available.

The six matrix columns show reference detection, primary coverage, reviewer flags, self-reported confidence, reference quality, and input limitations. They describe this evaluation rather than borrow measurements from earlier studies.

Unmatched flags may identify valid additional issues. The pilot has no clean-paper controls, human reviewer comparison or independent expert adjudication. It therefore cannot estimate hallucination rate, score bias, confidence calibration, or whether either model is ready for autonomous peer review.

Read the evidence, not just the score

Each cell opens the original annotations, the complete model critique, the matching rationale and the recorded run. Public benchmark exposure, text-only figure omission and single-run variability limit interpretation. A shared automated judge also creates a potential source of scoring bias. These coverage counts cannot be compared directly with the original SPOT headline rates: the corpus, text-only inputs, reference screen, prompt and scoring procedure differ.
